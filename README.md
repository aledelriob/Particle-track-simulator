# Particle Track Simulator

A simple simulation of particle trajectories in a detector system, created for a DESY Ausbildung application.

## Description

This program simulates particles emerging from a collision point and traveling through detector layers. It demonstrates basic concepts of particle physics and data analysis.

## Features

- Generate random particles with different properties
- Simulate particle trajectories
- Visualize detector hits
- Calculate basic statistics

## Technologies

- Python 3.14
- NumPy
- Matplotlib
